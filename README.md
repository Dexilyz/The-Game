# 🎡 Park Tycoon

Мобильная браузерная игра-тайкун: строй парк аттракционов, нанимай строителей,
привлекай инвесторов и развивай парк до 5 звёзд.

**Играть онлайн:** https://dexilyz.github.io/The-Game/ *(после включения GitHub Pages — см. ниже)*

## 🎮 Как играть

- **🔨 Build** — выбери аттракцион и поставь его на свободную траву
- **🛤️ Path** — проложи дорожки, чтобы посетители доходили до аттракционов
- **👷 Hire** — найми строителей: они физически идут на стройку и возводят аттракционы
- **💼 Invest** — принимай сделки от инвесторов (деньги в обмен на долю дохода)
- **📊 Stats** — статистика парка
- Перетаскивай для перемещения камеры, колесо/пинч — зум, 1×/2×/3× — скорость

## 🚀 Как опубликовать бесплатно (GitHub Pages)

Игра — это статические файлы, поэтому хостинг бесплатный и без серверов:

1. Открой репозиторий на GitHub → **Settings** → **Pages**
2. В разделе **Build and deployment** → **Source** выбери **Deploy from a branch**
3. **Branch**: `claude/tycoon-park-game-ymc42e`, папка **/ (root)** → **Save**
4. Через ~1 минуту игра будет доступна по адресу:
   **https://dexilyz.github.io/The-Game/**

> Можно сначала смёрджить ветку в `main` и публиковать из `main` — тогда URL тот же.

## 💻 Локальный запуск

Игра использует ES-модули, поэтому нужен локальный веб-сервер (не открывай
`index.html` напрямую через `file://`):

```bash
# Python 3
python3 -m http.server 8000
# затем открой http://localhost:8000

# или Node.js
npx serve
```

## 🏗️ Структура проекта

```
index.html        — разметка, HUD, панели
style.css         — стили мобильного интерфейса
src/
  data.js         — конфигурация: аттракционы, инвесторы, цвета, баланс
  utils.js        — A* поиск пути, математика, рисование
  park.js         — сетка парка, размещение объектов, дорожки
  character.js    — ИИ посетителей, строителей и инвесторов
  economy.js      — деньги, дни, рейтинг, расходы, доли инвесторов
  investment.js   — система появления и сделок с инвесторами
  renderer.js     — Canvas-отрисовка тайлов, аттракционов, персонажей
  ui.js           — панели, кнопки, уведомления
  game.js         — главный цикл, ввод (тач/мышь), связка систем
```

Без зависимостей и сборки — чистый JavaScript на Canvas 2D.
